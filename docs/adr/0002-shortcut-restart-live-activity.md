# ADR-0002：以捷徑定時重開 Live Activity

- 狀態：已採用
- 日期：2026-10-20

## 背景

iOS 的 Live Activity 最長約 8 小時後會被系統結束。希望卡片能一直掛在鎖定畫面，而不用每 8 小時手動打開 App。

## 考慮過的選項

| 選項 | 優點 | 缺點 |
|---|---|---|
| 手動重開 | 最簡單 | 使用者體驗差 |
| APNs push-to-start（iOS 17.2+） | 全自動、可遠端更新 | 需付費開發者帳號 |
| **捷徑定時執行 `LiveActivityIntent`** | 免費、背景執行不開 App | 只能固定時間觸發；數字需手動按更新 |

## 決定

App 提供 `RestartUsageActivityIntent`（抓資料 → 開新卡片 → 結束舊卡片；任一步失敗時保留舊卡片），使用者在捷徑 App 建立 3 個間隔 ≤ 8 小時的定時自動化。數字更新由卡片上的 `RefreshUsageIntent` 按鈕處理；重置倒數由 SwiftUI 依絕對時間自動計算。

## 影響

- 未來若改用付費帳號，可改為 push-to-start + 推播更新，捷徑與按鈕可保留作為備援。
