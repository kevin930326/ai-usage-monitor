# 需求規格

## 1. 目的

讓同時使用 Claude 與 Codex 的開發者，不用打開電腦就能在 iPhone 鎖定畫面掌握剩餘額度，避免工作到一半被限流。

## 2. 範圍

**包含**
- Claude：5 小時視窗、每週視窗的使用率與重置時間
- Codex：每週視窗（及有提供的其他視窗）的使用率與重置時間
- iPhone 鎖定畫面／動態島的 Live Activity 顯示
- iPhone 主畫面與鎖定畫面小工具（FR-31、FR-32）
- 手動更新按鈕、捷徑定時重開
- Mac 選單列 App 的額度歷史、額度消耗與這台 Mac 的 Token 統計（FR-33～FR-47、FR-50，只存在本機）
- 多裝置 Token 合併（FR-48、FR-49，v2.0，見 [ADR-0011](adr/0011-multi-device-usage.md)）
- Mac 與 iPhone 的外觀設定（FR-51、FR-52）
- 安裝與配對：Mac 一鍵安裝與內建收集器、首次設定精靈、iPhone 配對、一鍵部署中繼、Windows 一行安裝（FR-53～FR-57，見 [ADR-0012](adr/0012-iphone-pairing.md)、[ADR-0013](adr/0013-download-and-install.md)）

**不包含**
- Android（可列為未來擴充）
- 多使用者、帳號系統、多帳號切換
- Claude 與 Codex 以外的服務（provider 架構保留擴充空間）
- APNs 遠端推播（需付費帳號，列為未來擴充）
- 手機 App、claude.ai 網頁與雲端 session 的 Token 數（沒有本機紀錄；不讀瀏覽器 cookie，違反條款）
- 各專案的統計（會碰到專案路徑）

### 3.5 iPhone 小工具

| ID | 需求 | 優先度 | 里程碑 |
|---|---|---|---|
| FR-31 | iPhone 主畫面小工具（小、中、大）：小為剩餘最少的額度，中與 Live Activity 卡片相同，大為剩餘最少的額度加上所有額度；中、大有「更新」按鈕。顯示規則同 FR-11、FR-12、FR-15～FR-17、FR-26 | Could | v0.6 |
| FR-32 | iPhone 鎖定畫面小工具（圓形、矩形、單行）：顯示剩餘最少的額度的 % 與服務圖示，鎖定時也看得到 | Could | v0.6 |

- **資料來源**：小工具自己以 App 的讀取密鑰（共用的 Keychain 項目）呼叫中繼 `GET /usage`，不必等 App 開啟；網址與顯示模式放在 App Group 的 UserDefaults，最後一份資料存在 App Group 的 `usage.json`，抓不到中繼時顯示它並依資料時間轉灰。密鑰仍只在 Keychain（NFR-1）。
- **更新預算**：WidgetKit 每天約 40～70 次。小工具每 25 分鐘重新整理（資料過期時每小時），App 在背景取得新資料時另外 reload，一般約 51 次／天、最多約 63 次；重置與過期時間點放在 timeline，不扣次數。計算見 [`apple/iOSApp/README.md`](../apple/iOSApp/README.md#重新整理次數)。
- **部署目標**：與 Live Activity 同一個 Widget 擴充（iOS 18 以上），App 本身仍支援 iOS 17。

| NFR-7 重用 | iOS、watchOS 與 Mac 共用同一個 Swift Package（資料模型、解析、顏色規則） |
| NFR-8 耗能 | Mac App 的動畫只在面板或統計視窗開啟時執行，關閉時不佔 CPU／GPU（包含系統自動更新的相對時間文字） |
| NFR-9 隱私 | 讀取本機對話紀錄時只取 token 數、模型、時間與配對用的 ID（白名單，見 ADR-0009 第 3 節）；不保存或輸出對話內容、提示詞、檔案路徑、專案名稱、工作目錄與帳號資訊；不開啟任何憑證檔。統計只存在本機，第二層只上傳每日加總 |
| NFR-10 效能 | 每個 Mac 動畫都以 `ps` 量測面板開啟、播放中與關閉後 1 分鐘的 CPU% 與記憶體：開啟靜止 ≤ 2%、關閉後 1 分鐘 ≤ 0.3%、重複開關後記憶體不累積（ADR-0010 第 3 節）；收集器的 Token 統計一般每次執行增加 < 1 秒，首次掃描分段（每次 ≤ 64 MB 或 15 秒） |

## 5. 已知限制

- Live Activity 最長約 8 小時後由系統結束 → 以捷徑定時重開處理。
- 免費 Apple ID 簽署的 App 7 天後需重新安裝。
- 手錶 App（`apple/WatchApp`）是獨立的 Xcode 專案，沒有嵌入 iOS App，目前只能用 Xcode 直接裝到手錶自用。若要以 TestFlight（或 App Store）散佈，需要先把手錶 App 嵌入 iOS App，一起封存上傳。
- 用量 API 為非公開介面，可能隨時變更。
- **Mac 關機或睡眠時收集器停止更新**，手機只能顯示最後一筆資料。緩解方式：
  - 讓 Mac 插電時不自動睡眠（見[收集器說明](../collector/README.md#讓-mac-保持清醒)）；闔上螢幕仍會睡眠。
  - 重置時間過後改顯示「已重置」（FR-26）。
  - 仍無法反映 Mac 離線期間在手機或網頁上使用 claude.ai 的用量。
